# Historical Documentation

This directory preserves superseded planning and deployment investigations for
provenance. They document why the project moved from RunPod and
nested-container approaches to the validated AWS Docker-native runtime.

Do not use these files as execution instructions. Current material is listed
in the [documentation index](../README.md).

- `runpod/`: RunPod runtime, container, and recovery investigations.
- `remote_snakemake/`: generic Snakemake/Apptainer handoff guidance for
  environments that were not used for the completed pilot.
- `planning/`: early repository and interaction-panel design documents.

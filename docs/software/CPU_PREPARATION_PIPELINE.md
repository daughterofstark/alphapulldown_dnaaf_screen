# CPU Preparation Pipeline

## Purpose

The local macOS workflow prepares deterministic AlphaPulldown inputs without installing AlphaPulldown, AlphaFold, CUDA, or large sequence databases. It validates verified UniProt targets, writes canonical FASTA files, constructs benchmark and screen definitions, prepares AlphaPulldown-compatible accession lists, and records provenance.

Inference remains a future Linux + NVIDIA CUDA task.

## Inputs

- `data/processed/uniprot/targets_uniprot_verified.json`: tracked verified metadata.
- `data/raw/uniprot/*.json`: local raw UniProt sequence snapshots generated by the retrieval script.
- `config/alphapulldown.example.yaml`: GPU-environment template.

## Commands

```bash
python -m alphapulldown_dnaaf_screen.cli validate-targets
python -m alphapulldown_dnaaf_screen.cli write-fastas
python -m alphapulldown_dnaaf_screen.cli build-screens
python -m alphapulldown_dnaaf_screen.cli prepare-alphapulldown
```

## Local Mac Boundary

The local machine is used for preparation, validation, parsing, and documentation only. It should not run AlphaFold-Multimer inference because it lacks NVIDIA CUDA support.

## GPU Handoff

When Linux GPU access is available, transfer the repository plus generated `data/processed/alphapulldown/` inputs and configure machine-specific paths from `config/alphapulldown.example.yaml`.
